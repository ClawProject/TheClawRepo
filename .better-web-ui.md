# Design context — Claw

## Product

Claw is a self-hosted WhatsApp assistant for a school class group. It remembers homework and
exams, answers from a local database and keeps everything on the machine that runs it. The
public site is a single static page (plain HTML/CSS/JS, ten languages) whose job is to explain
the product and get a technical user to install it.

## Audience

- **Primary:** a student or teacher who is comfortable with a terminal, owns the machine, and
  wants the class group to stop losing homework. Reads on a laptop, sometimes on a phone in class.
- **Secondary:** a self-hosting enthusiast evaluating whether the project is real and maintained.
- **Trust level needed:** high. The pitch is privacy and local inference, so the page must read as
  factual and unhyped. No growth-marketing tone.

## Jobs to be done

1. Understand in ten seconds what Claw does inside a WhatsApp group.
2. Believe that nothing leaves the machine.
3. See the install path (three commands) and the commands they will use daily.
4. Reach the repository or the docs.

## Brand personality

Sober, exact, school-notebook honest. Three words: **orderly, plain-spoken, local**.

- Should feel like a well-set technical document, not a SaaS landing page.
- Should NOT look like: purple-gradient AI SaaS, glassmorphism dashboards, neon/terminal
  cosplay, playful illustration-heavy startup sites, or decorative 3D.

## Direction

- **Primary structural direction:** Swiss Style — modular grid, strict alignment, poster-like
  composition, controlled asymmetry, sans-serif type, hairline rules instead of cards.
- **Modifier:** restrained motion (state feedback only, under 200 ms, nothing looping).
- **Levers:** one signal red accent used for emphasis and structure; square corners; flat
  surfaces; numbers as index marks; honest plain copy.
- **Clarity first:** install commands, command list and FAQ stay utilitarian; expression lives in
  the hero, section rules and the footer block.

## Constraints

- Single static file, no build step, no framework, no new dependencies.
- Ten locales share one dictionary keyed by `data-i18n`; copy must not be duplicated or invented.
- WCAG AA for body text; visible focus; keyboard-operable menu; copy feedback announced.
- No blur, no heavy shadows, no looping animation; motion respects `prefers-reduced-motion`.
- Page weight stays small: system-friendly fonts with two Google families at most.
